# Image to PDF — Internal Demo Script

Duration: ~60 seconds

---

## Scene 1: Home (3s)
**Action:** Show home screen
**Voice:** "Here's the Image to PDF feature. Let me walk through the full flow."

## Scene 2: Pick Images (8s)
**Action:** Tap Image to PDF → switch to Camera folder → select 4 images → preview one full screen → swipe → confirm
**Voice:** "First step is the image picker. Users browse folders, select images in order, and can preview any image full screen. Once they're happy with the selection, they confirm and move to the editor."

## Scene 3: Editor — Rotate & Crop (10s)
**Action:** Show editor → rotate once → tap Crop → adjust corners → apply
**Voice:** "This is the editor. The bottom toolbar has all the tools. Starting with the basics — rotate and crop."

## Scene 4: Editor — Filter (5s)
**Action:** Tap Filter → pick Auto → close
**Voice:** "Next, filters. Five presets that apply in real time. Moving on to page settings."

## Scene 5: Editor — Page Size (8s)
**Action:** Tap Page Size → select A4 Portrait → show page frame → switch to Landscape
**Voice:** "Page Size lets users pick Fit, A4, Letter, or Legal, each in portrait or landscape. The canvas preview updates live to show exactly how the PDF will look."

## Scene 6: Editor — Placement (6s)
**Action:** Tap Placement → change Fill to Fill → change Margin to Small
**Voice:** "Placement controls how the image sits on the page — fill mode and margin. These settings are per-image, not global, so each page can be different."

## Scene 7: Editor — Navigate & Reorder (6s)
**Action:** Use arrows to switch images → tap Reorder → drag to reorder → done
**Voice:** "Users navigate between pages with arrows or the thumbnail strip. They can also reorder or delete pages from the reorder view. Once everything looks good, they tap Done to go to preview."

## Scene 8: Preview (5s)
**Action:** Show Preview page → scroll through list
**Voice:** "The preview page shows all pages with the selected page size applied. From here, they tap Convert."

## Scene 9: Convert & Done (8s)
**Action:** Tap Convert → enter filename → tap Convert → progress → success screen
**Voice:** "They name the file, hit convert, and the PDF is generated client-side using jsPDF. No server upload — everything stays on the device. They can open or share the result directly."
