# Image to PDF — Screen Recording Script

Target: ~2 minutes, internal demo for leadership and team
Format: Phone screen recording + AI voiceover (CapCut/剪映)

---

## How to record

1. Open the prototype on your phone
2. Start screen recording
3. Follow the actions below at a relaxed pace — no rush
4. Pause 1-2 seconds between each step so the AI voice has room
5. After recording, paste the voiceover text into CapCut AI narration

---

## Script

### 0. Intro (0:00 - 0:08)

**Action:** Show the prototype running on phone (PDF Tools home visible).

**Voiceover:**
"Hey everyone. This is a fully interactive prototype of PDF Tools, built entirely through conversation with Kiro — no manual coding involved. Let me walk you through it."

---

### 1. App Home → PDF Tools Home (0:08 - 0:20)

**Action:** Tap "PDF Tools" on the app home page. Show the PDF Tools home — slowly scroll the tool grid to show all 8 tools. Then scroll down to show the PDF file list. Tap the sort button, change sort to "Name", tap Done. Scroll back up.

**Voiceover:**
"Starting from the app home, we tap into PDF Tools. The top section gives quick access to all tools — Image to PDF, Scan, ID Card, PDF to Image, Compress, Merge, Extract, and more. Below that, users see all PDF files on their device, sorted by date, name, or size."

---

### 2. PDF Home — File Preview (0:12 - 0:22)

**Action:** Tap on a regular (unlocked) PDF file to open the viewer. Show a page or two. Go back. Then tap on a locked file — password dialog appears — type a password — file opens. Go back to home.

**Voiceover:**
"Tapping any file opens a built-in PDF viewer. Password-protected files prompt for the password before opening. Now let me show the Image to PDF flow as an example."

---

### 3. Image Picker (0:22 - 0:35)

**Action:** Tap "Image to PDF". The swipe guide appears — tap to dismiss. Switch folder to "Camera". Select 4-5 images. Scroll down to show more images available.

**Voiceover:**
"Users pick their images from the gallery. They can browse by folder, and a first-time guide shows them they can swipe to multi-select. Let me grab a few photos."

---

### 4. Confirm & Enter Editor (0:35 - 0:40)

**Action:** Tap "Confirm" at the bottom. Auto crop dialog appears — choose an option. Editor opens showing the first image.

**Voiceover:**
"After confirming, users choose whether to auto-crop. Then we land in the editor."

---

### 5. Editor — Rotate & Crop (0:40 - 0:52)

**Action:** Tap Rotate once. Then tap Crop — drag a corner — tap Apply.

**Voiceover:**
"The editor toolbar gives quick access to all editing tools. Rotate fixes orientation. Crop lets users drag the corners to trim any unwanted edges."

---

### 6. Editor — Filter (0:52 - 0:59)

**Action:** Tap Filter. Try "Magic" or "Grayscale". Then pick one and close.

**Voiceover:**
"Filters enhance the image. Magic boosts contrast and clarity — great for scanned documents. Five presets, all real-time preview."

---

### 7. Editor — Page Size (0:59 - 1:09)

**Action:** Tap Page Size. Select "A4 Portrait" — show the page frame appear. Switch to "A4 Landscape". Then back to Portrait.

**Voiceover:**
"Page Size controls the PDF output. Users pick from Fit, A4, Letter, or Legal, in portrait or landscape. The canvas updates live so they see exactly how the page will look."

---

### 8. Editor — Placement (1:09 - 1:17)

**Action:** Tap Placement. Change Fill to "Fill". Change Margin to "Small". Toggle "Apply to all".

**Voiceover:**
"Placement controls how the image sits on the page — fit, fill, or stretch — plus margin for print-friendly spacing. These can be set per image or applied to all at once."

---

### 9. Editor — Navigate Pages (1:17 - 1:25)

**Action:** Use the arrows to go to image 2, then 3. Scroll the thumbnail strip. Tap a thumbnail to jump.

**Voiceover:**
"Users navigate between pages using arrows or the thumbnail strip at the bottom. Each page can have its own settings."

---

### 10. Preview (1:25 - 1:32)

**Action:** Tap "Done" to go to Preview. Scroll through the list view. Toggle to grid view briefly.

**Voiceover:**
"The preview page shows all pages with the selected layout applied. Users can switch between list and grid view for a final check."

---

### 11. Convert & Done (1:32 - 1:47)

**Action:** Tap "Convert". Enter a filename. Tap "Convert" again. Watch the progress ring. Success page appears. Tap "Open" to preview the PDF.

**Voiceover:**
"They name the file, tap convert, and the PDF is generated entirely on-device. No server upload needed. From the result page, they can share or open the PDF directly."

---

## Tips for recording

- Keep your finger movements smooth and deliberate
- Don't tap too fast — give each screen 1-2 seconds to breathe
- If you make a mistake, just keep going — you can trim in CapCut
- Record in portrait mode (matches the prototype)
- Turn off notifications before recording
